# prd-auto-executor Skill

**Pattern**: Linear Execution Protocol (Semi-Automated with Git Safety)
**Version**: 1.1.0
**Purpose**: Execute PRD-based checklists with user approval, Git checkpoints, and automatic rollback

---

## 📋 Input Requirements

Before starting, you need:

1. **Checklist Path** (flexible filename):
   - Example: `prd_checklist.json`, `checklist.json`, `./tasks.json`
   - Must be JSON file generated by prd-implementation-tracker (Step 4.3)
   - If user doesn't provide, ask: "체크리스트 파일 경로를 입력해주세요"

2. **Project Path**:
   - Root directory of project (where package.json is located)
   - If user doesn't provide, use current working directory
   - Validate: package.json exists in this path

3. **Optional: Resume State**:
   - execution_state.json may exist if previous session was interrupted
   - Auto-detect and ask user if they want to resume

## 🎯 Execution Protocol

### Phase 1: Initialization (Step 0-2)

#### Step 0: Check for Resume State

```javascript
// Check if execution_state.json exists
const projectPath = "[user-provided or cwd]";
const stateFilePath = `${projectPath}/execution_state.json`;
let state = null;
let shouldResume = false;

try {
  const stateContent = Read({ file_path: stateFilePath });
  state = JSON.parse(stateContent);

  if (state && state.status === 'in_progress') {
    console.log(`\n━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━`);
    console.log(`⏸️  이전 세션 발견`);
    console.log(`━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━\n`);
    console.log(`**프로젝트**: ${state.project}`);
    console.log(`**마지막 작업**: ${state.currentTask}`);
    console.log(`**진행률**: Task ${state.taskIndex + 1}/${state.totalTasks}\n`);

    const resumeResponse = await AskUserQuestion({
      questions: [{
        question: `이전 세션을 재개하시겠습니까?\n\n**마지막 작업**: ${state.currentTask}\n**진행률**: Task ${state.taskIndex + 1}/${state.totalTasks}`,
        header: "세션 재개",
        options: [
          { label: "재개", description: `Task ${state.taskIndex + 1}부터 계속` },
          { label: "처음부터", description: "모든 작업 다시 시작" },
          { label: "취소", description: "실행 취소" }
        ],
        multiSelect: false
      }]
    });

    const resumeChoice = resumeResponse.answers["세션 재개"];

    if (resumeChoice === "취소") {
      console.log(`\n❌ 실행을 취소했습니다.`);
      return;
    }

    if (resumeChoice === "재개") {
      shouldResume = true;
      console.log(`\n✅ Task ${state.taskIndex + 1}부터 재개합니다.`);
    } else {
      // "처음부터" 선택
      shouldResume = false;
      console.log(`\n🔄 처음부터 다시 시작합니다.`);
      state = null; // Reset state
    }
  }
} catch (error) {
  // execution_state.json doesn't exist - fresh start
  console.log(`\nℹ️  새로운 세션을 시작합니다.`);
  shouldResume = false;
  state = null;
}
```

### Phase 2: Task Execution Loop (Step 3-10)

```javascript
// Task execution loop
for (let taskIndex = state.taskIndex; taskIndex < totalTasks; taskIndex++) {
  const task = checklist.tasks[taskIndex];
  const checkpointTag = `checkpoint-${taskIndex}`;

  console.log(`\n━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━`);
  console.log(`Task ${taskIndex + 1}/${totalTasks}: ${task.name}`);
  console.log(`━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━\n`);
  console.log(`**설명**: ${task.description}`);
  console.log(`**우선순위**: ${task.priority || 'normal'}`);
  console.log(`**예상 시간**: ${task.estimatedTime || 'unknown'}\n`);

  // Step 3: Create Git Checkpoint
  console.log(`⏳ Git checkpoint 생성 중...`);

  // Delete existing checkpoint if any
  await Bash({
    command: `git tag -d ${checkpointTag} 2>/dev/null || true`,
    description: `Delete existing checkpoint (if any)`,
    timeout: 10000
  });

  // Create new checkpoint
  await Bash({
    command: `git tag ${checkpointTag}`,
    description: `Create Git checkpoint for task ${taskIndex}`,
    timeout: 10000
  });

  console.log(`✅ Checkpoint created: ${checkpointTag}\n`);

  // Step 4: Request User Approval
  const approvalResponse = await AskUserQuestion({
    questions: [{
      question: `작업을 진행하시겠습니까?\n\n**${task.name}**\n${task.description}\n\n**우선순위**: ${task.priority || 'normal'}\n**예상 시간**: ${task.estimatedTime || 'unknown'}`,
      header: "작업 승인",
      options: [
        { label: "승인", description: "테스트/빌드 후 자동 커밋" },
        { label: "건너뛰기", description: "다음 작업으로 이동" },
        { label: "중단", description: "전체 실행 중단" }
      ],
      multiSelect: false
    }]
  });

  const approval = approvalResponse.answers["작업 승인"];

  // Handle user decision
  if (approval === "중단") {
    console.log(`\n❌ 사용자가 실행을 중단했습니다.`);
    state.status = 'failed';
    state.taskIndex = taskIndex;
    state.currentTask = task.name;
    Write({ file_path: stateFilePath, content: JSON.stringify(state, null, 2) });
    return;
  }

  if (approval === "건너뛰기") {
    console.log(`\n⏭️  작업을 건너뜁니다: ${task.name}`);
    state.skippedTasks.push({
      taskIndex,
      name: task.name,
      reason: 'user_skipped',
      skippedAt: new Date().toISOString()
    });
    state.taskIndex = taskIndex + 1;
    Write({ file_path: stateFilePath, content: JSON.stringify(state, null, 2) });
    continue; // Move to next task
  }

  // Step 5: Execute Task (approval === "승인")
  state.status = 'in_progress';
  state.taskIndex = taskIndex;
  state.currentTask = task.name;
  Write({ file_path: stateFilePath, content: JSON.stringify(state, null, 2) });

  let taskSuccess = false;
  const maxRetries = 3;

  while (!taskSuccess && state.retryCount < maxRetries) {
    try {
      console.log(`\n⏳ Task 실행 중... (시도 ${state.retryCount + 1}/${maxRetries})`);
      console.log(`\n━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━`);
      console.log(`🤖 Claude가 작업을 수행합니다...`);
      console.log(`━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━\n`);

      // ⚠️ IMPORTANT: Claude performs the task here
      // The actual task execution happens here based on task.description
      // Claude should use Read, Write, Edit, Bash, etc. to complete the task

      console.log(`\n✅ Task 실행 완료\n`);

      // Step 6: Validation (SDD-style: test/build/lint)
      console.log(`⏳ 검증 중...\n`);

      // Run npm test
      console.log(`  - npm test 실행 중...`);
      const testResult = await Bash({
        command: "npm test",
        description: "Run tests for validation",
        timeout: 300000 // 5 minutes
      });

      if (testResult.exitCode !== 0) {
        throw new Error(`Tests failed:\n${testResult.stderr}`);
      }
      console.log(`    ✅ Pass (${testResult.duration}ms)`);

      // Run npm run build
      console.log(`  - npm run build 실행 중...`);
      const buildResult = await Bash({
        command: "npm run build",
        description: "Build project for validation",
        timeout: 600000 // 10 minutes
      });

      if (buildResult.exitCode !== 0) {
        throw new Error(`Build failed:\n${buildResult.stderr}`);
      }
      console.log(`    ✅ Pass (${buildResult.duration}ms)`);

      // Run npm run lint (optional - skip if not available)
      console.log(`  - npm run lint 실행 중...`);
      try {
        const lintResult = await Bash({
          command: "npm run lint",
          description: "Lint code for validation",
          timeout: 120000 // 2 minutes
        });

        if (lintResult.exitCode === 0) {
          console.log(`    ✅ Pass (${lintResult.duration}ms)`);
        } else {
          console.log(`    ⚠️  Warnings (non-blocking)`);
        }
      } catch (lintError) {
        console.log(`    ⏭️  Skipped (script not available)`);
      }

      console.log(`\n✅ 검증 완료\n`);

      // Step 7: Git Commit (on success)
      console.log(`⏳ Git commit 중...`);

      const commitMessage = `✅ ${task.name}\n\n${task.description}\n\n🤖 Generated with prd-auto-executor`;

      await Bash({
        command: `git add . && git commit -m "${commitMessage}"`,
        description: `Commit task ${taskIndex}: ${task.name}`,
        timeout: 30000
      });

      console.log(`✅ Git commit 완료\n`);

      // Task succeeded!
      taskSuccess = true;
      state.completedTasks.push({
        taskIndex,
        name: task.name,
        completedAt: new Date().toISOString(),
        retries: state.retryCount
      });
      state.retryCount = 0;
      state.taskIndex = taskIndex + 1;
      Write({ file_path: stateFilePath, content: JSON.stringify(state, null, 2) });

      console.log(`✅ Task ${taskIndex + 1} 완료: ${task.name}\n`);

    } catch (error) {
      // Step 8: Failure Handling - Git Rollback
      console.log(`\n❌ Task 실행 실패\n`);
      console.log(`**에러**: ${error.message}\n`);

      console.log(`⏳ Git rollback 중...`);

      await Bash({
        command: `git reset --hard ${checkpointTag} && git clean -fd`,
        description: `Rollback to ${checkpointTag}`,
        timeout: 30000
      });

      console.log(`✅ Rollback 완료: ${checkpointTag}\n`);

      // Increment retry count
      state.retryCount += 1;
      Write({ file_path: stateFilePath, content: JSON.stringify(state, null, 2) });

      // Step 9: Retry Logic
      if (state.retryCount >= maxRetries) {
        console.log(`\n❌ Task failed after ${maxRetries} retries: ${task.name}\n`);

        state.failedTasks.push({
          taskIndex,
          name: task.name,
          error: error.message,
          failedAt: new Date().toISOString(),
          retries: state.retryCount
        });

        // Ask user: skip or abort
        const failureResponse = await AskUserQuestion({
          questions: [{
            question: `작업이 ${maxRetries}회 재시도 후에도 실패했습니다.\n\n**${task.name}**\n\n**에러**:\n${error.message}\n\n계속 진행하시겠습니까?`,
            header: "재시도 실패",
            options: [
              { label: "건너뛰기", description: "다음 작업으로 이동" },
              { label: "중단", description: "전체 실행 중단" }
            ],
            multiSelect: false
          }]
        });

        const failureChoice = failureResponse.answers["재시도 실패"];

        if (failureChoice === "중단") {
          console.log(`\n❌ 사용자가 실행을 중단했습니다.`);
          state.status = 'failed';
          Write({ file_path: stateFilePath, content: JSON.stringify(state, null, 2) });
          return;
        }

        // Skip this task and move to next
        console.log(`\n⏭️  작업을 건너뛰고 계속 진행합니다.`);
        state.retryCount = 0;
        state.taskIndex = taskIndex + 1;
        Write({ file_path: stateFilePath, content: JSON.stringify(state, null, 2) });
        break; // Exit retry loop, move to next task

      } else {
        // Step 10: Ask User to Retry
        console.log(`\n⚠️  재시도 가능 (${state.retryCount}/${maxRetries})\n`);

        const retryResponse = await AskUserQuestion({
          questions: [{
            question: `작업 실패 (재시도 ${state.retryCount}/${maxRetries})\n\n**${task.name}**\n\n**에러**:\n${error.message}\n\n재시도하시겠습니까?`,
            header: "재시도 확인",
            options: [
              { label: "재시도", description: `${state.retryCount}/${maxRetries}회 재시도` },
              { label: "건너뛰기", description: "다음 작업으로" },
              { label: "중단", description: "전체 중단" }
            ],
            multiSelect: false
          }]
        });

        const retryChoice = retryResponse.answers["재시도 확인"];

        if (retryChoice === "중단") {
          console.log(`\n❌ 사용자가 실행을 중단했습니다.`);
          state.status = 'failed';
          Write({ file_path: stateFilePath, content: JSON.stringify(state, null, 2) });
          return;
        }

        if (retryChoice === "건너뛰기") {
          console.log(`\n⏭️  작업을 건너뛰고 계속 진행합니다.`);
          state.skippedTasks.push({
            taskIndex,
            name: task.name,
            reason: 'failed_and_skipped',
            error: error.message,
            retries: state.retryCount,
            skippedAt: new Date().toISOString()
          });
          state.retryCount = 0;
          state.taskIndex = taskIndex + 1;
          Write({ file_path: stateFilePath, content: JSON.stringify(state, null, 2) });
          break; // Exit retry loop, move to next task
        }

        // retryChoice === "재시도"
        console.log(`\n🔄 재시도합니다...\n`);
        // Loop continues - retry the task
      }
    }
  }
}
```

```javascript
// All tasks processed
console.log(`\n━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━`);

console.log(`━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━\n`);

console.log(`**프로젝트**: ${state.project}`);

const startTime = new Date(state.startedAt);
const endTime = new Date();
const duration = endTime - startTime;
const durationMin = Math.floor(duration / 60000);
const durationSec = Math.floor((duration % 60000) / 1000);

console.log(`**총 소요 시간**: ${durationMin}분 ${durationSec}초\n`);

// Display completed tasks
if (state.completedTasks.length > 0) {

// Display failed tasks
if (state.failedTasks.length > 0) {
  console.log(`\n❌ 실패한 작업 (${state.failedTasks.length}):`);
  state.failedTasks.forEach((t, i) => {
    console.log(`  ${i + 1}. ${t.name}`);
    console.log(`     - 에러: ${t.error}`);

// Display skipped tasks
if (state.skippedTasks.length > 0) {
  console.log(`\n⏭️  건너뛴 작업 (${state.skippedTasks.length}):`);
  state.skippedTasks.forEach((t, i) => {
    const reasonText = t.reason === 'user_skipped'
      ? '사용자 요청'

    console.log(`  ${i + 1}. ${t.name} - ${reasonText}`);
  });
}

// Update final state
state.status = 'completed';
state.completedAt = new Date().toISOString();
Write({ file_path: stateFilePath, content: JSON.stringify(state, null, 2) });

// Clean up Git checkpoints
console.log(`\n⏳ Git checkpoint 정리 중...`);
for (let i = 0; i < totalTasks; i++) {
  await Bash({
    command: `git tag -d checkpoint-${i} 2>/dev/null || true`,
    description: `Delete checkpoint-${i}`,
    timeout: 10000
  });
}
console.log(`✅ Checkpoint 정리 완료\n`);

console.log(`\n━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━`);
console.log(`📊 실행 결과가 execution_state.json에 저장되었습니다.`);
console.log(`━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━\n`);
```

## ✅ Safety Checklist

Before executing each task, verify:

- [ ] **Step 3**: Git checkpoint created successfully (tag exists)
- [ ] **Step 4**: User approval obtained (승인/건너뛰기/중단)
- [ ] **Step 5**: Task execution completed by Claude
- [ ] **Step 6**: Validation passed (npm test, npm run build)
- [ ] **Step 7**: Git commit successful (changes committed)
- [ ] **Step 8**: State saved to execution_state.json
- [ ] **Step 9**: Retry logic applied on failure (max 3 retries)
- [ ] **Step 10**: User retry approval obtained (if needed)

---

## 🚫 Prohibited Actions

**NEVER**:
1. Execute tasks without user approval (Step 4)
2. Skip validation steps (Step 6)
3. Commit without test/build passing (Step 7)
4. Modify the checklist JSON file (read-only)
5. Delete checkpoints before rollback opportunity
6. Run destructive Git commands without approval
7. Execute arbitrary shell commands outside validation
8. Ignore error handlers

**ALWAYS**:
1. Request user approval before each task (Step 4)
2. Create checkpoint before task (Step 3)
3. Run validation after task (Step 6)
4. Rollback on validation failure (Step 8)
5. Save state after every operation (Step 8)
6. Display clear progress (console.log)
7. Handle errors gracefully (try-catch)
8. Use safe Git commands only (tag, commit, reset --hard)

## 🔧 Error Scenarios

### Error 1: Checklist File Not Found

**Symptom**: `Read({ file_path: checklistPath })` fails

**Fix**:
```javascript
try {
  const checklistContent = Read({ file_path: checklistPath });
} catch (error) {
  console.log(`\n❌ 오류: 체크리스트 파일을 찾을 수 없습니다.`);
  console.log(`\n경로: ${checklistPath}`);
  console.log(`\n올바른 경로를 입력해주세요.`);
  throw error;
}
```

---

### Error 2: Invalid Checklist Format

**Symptom**: `checklist.tasks` is not an array

**Fix**:
```javascript
if (!checklist.tasks || !Array.isArray(checklist.tasks)) {
  console.log(`\n❌ 오류: 유효하지 않은 체크리스트 형식입니다.`);
  console.log(`\n체크리스트에는 'tasks' 배열이 필요합니다.`);
  console.log(`\n예시:`);
  console.log(`{`);
  console.log(`  "project": "my-project",`);
  console.log(`  "tasks": [`);
  console.log(`    { "name": "Task 1", "description": "..." },`);
  console.log(`    { "name": "Task 2", "description": "..." }`);
  console.log(`  ]`);
  console.log(`}`);
  throw new Error("Invalid checklist format");
}
```

---

### Error 3: Git Checkpoint Already Exists

**Symptom**: `git tag checkpoint-N` fails (tag already exists)

**Fix**:
```javascript
// Always delete existing checkpoint first
await Bash({
  command: `git tag -d ${checkpointTag} 2>/dev/null || true`,
  description: `Delete existing checkpoint (if any)`,
  timeout: 10000
});

// Then create new checkpoint
await Bash({
  command: `git tag ${checkpointTag}`,
  description: `Create Git checkpoint for task ${taskIndex}`,
  timeout: 10000
});
```

---

### Error 4: Validation Timeout

**Symptom**: npm test or npm run build exceeds timeout

**Fix**:
```javascript
// Increase timeout for slow projects
const testResult = await Bash({
  command: "npm test",
  description: "Run tests for validation",
  timeout: 600000 // Increase to 10 minutes if needed
});
```

---

### Error 5: State File Corrupted

**Symptom**: `JSON.parse(stateContent)` fails

**Fix**:
```javascript
try {
  const stateContent = Read({ file_path: stateFilePath });
  state = JSON.parse(stateContent);
} catch (error) {
  console.log(`\n⚠️  경고: execution_state.json 파일이 손상되었습니다.`);
  console.log(`\n새로운 세션을 시작합니다.`);
  state = null;
  shouldResume = false;
}
```

---

### Error 6: Git Reset Failed

**Symptom**: `git reset --hard` fails

**Fix**:
```javascript
try {
  await Bash({
    command: `git reset --hard ${checkpointTag} && git clean -fd`,
    description: `Rollback to ${checkpointTag}`,
    timeout: 30000
  });
} catch (resetError) {
  console.log(`\n❌ 오류: Git rollback 실패`);
  console.log(`\n수동으로 복구가 필요합니다:`);
  console.log(`\ngit reset --hard ${checkpointTag}`);
  console.log(`git clean -fd`);
  throw resetError;
}
```

## 📊 Token Budget

**Total prd-auto-executor Execution: ~400-600 tokens** (varies by checklist size)

**Breakdown**:
- Phase 1 Initialization: ~80 tokens
  - Step 0 (Resume check): ~30 tokens
  - Step 1 (Load checklist): ~30 tokens
  - Step 2 (Initialize state): ~20 tokens

- Phase 2 Task Loop: ~40 tokens per task × N tasks
  - Step 3 (Checkpoint): ~10 tokens
  - Step 4 (Approval): ~15 tokens
  - Step 5-7 (Execute/Validate/Commit): ~15 tokens
  - Step 8-10 (Retry logic, if needed): +20 tokens

- Phase 3 Completion: ~60 tokens
  - Step 11 (Summary + cleanup): ~60 tokens

**Example** (10-task checklist):
- Phase 1: 80 tokens
- Phase 2: 40 × 10 = 400 tokens
- Phase 3: 60 tokens
- **Total: ~540 tokens** ✅ (within budget)


### Manual Git Checkpoint Recovery

```bash
# List all checkpoints
git tag | grep checkpoint

# Rollback to specific checkpoint
git reset --hard checkpoint-3
git clean -fd

# Delete all checkpoints
git tag | grep checkpoint | xargs git tag -d
```
